# Сервер личного ИИ-агента

Node.js API для Android-клиента.

## Запуск

1. Установить Node.js 20 или новее.
2. Скопировать `.env.example` в `.env`.
3. Указать `OPENAI_API_KEY` и длинный случайный `AGENT_API_TOKEN`.
4. Выполнить `npm install` и `npm start`.

Проверка: `GET /health`.

Чат: `POST /v1/chat`, заголовок `Authorization: Bearer <AGENT_API_TOKEN>`, JSON `{ "message": "...", "language": "ru" }`.

Для актуальных запросов API использует Responses API и встроенный инструмент `web_search`. Ключ OpenAI хранится только на сервере и не должен попадать в APK, Git или клиентское приложение.

## Ограничения этой версии

Это начальный серверный слой: нет учётных записей, постоянной базы памяти, очереди фоновых заданий, Live-аудио, управления Android и внешних интеграций. Не выставляйте сервер в публичный интернет без HTTPS, ограничения частоты запросов и надёжной авторизации.
