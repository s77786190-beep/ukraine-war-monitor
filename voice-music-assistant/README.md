# Голосовой музыкальный помощник

Android-first веб-приложение с чёрным фоном и контрастным оранжевым интерфейсом.

## Что работает
- Голосовой ввод на русском через Web Speech API (если поддерживается браузером).
- Поиск композиций в публичном каталоге iTunes/Apple.
- Воспроизведение официального короткого preview, если он доступен.
- Переход на официальную страницу композиции.
- Ручной поиск, адаптивный интерфейс и крупные читаемые элементы.

## Ограничение загрузки
Приложение не скачивает полные защищённые авторским правом записи с посторонних сайтов. Полные треки доступны для загрузки только через официальные магазины/сервисы, если правообладатель разрешает загрузку. Preview предназначен для ознакомительного прослушивания.

## Запуск
Откройте `index.html` через локальный веб-сервер или опубликуйте каталог как GitHub Pages. Для микрофона браузеру обычно нужен HTTPS (GitHub Pages подходит).

## Важно
Это рабочая первая версия интерфейса и голосового поиска, а не готовый APK. Для APK потребуется отдельная Android-обёртка и успешная сборка в GitHub Actions.
