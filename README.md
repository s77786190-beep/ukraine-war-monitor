# Мониторинг Костромской области

Android-приложение для сбора и просмотра новостей и сообщений об инцидентах в Костроме и Костромской области.

## Уже добавлено

- Начальный экран приложения на русском языке.
- Чёрная тема с оранжевыми акцентами.
- Настройка частоты проверки с сохранением на устройстве.
- Варианты: 5, 10, 15, 20, 30, 45 минут; 1, 3, 5, 12 и 24 часа.
- Значение по умолчанию: 30 минут.
- GitHub Actions workflow для сборки Android APK и публикации APK как build artifact.

## Файлы

- `App.tsx` — интерфейс приложения и настройка интервала.
- `config/monitoring.json` — конфигурация интервала мониторинга.
- `docs/monitoring-intervals.md` — требования к планировщику.
- `.github/workflows/build-android.yml` — сборка APK.

## Состояние разработки

Это начальный каркас. Сбор новостей, подключение Telegram и других источников, серверный планировщик, хранение новостей, карта событий и фильтры ещё требуют реализации. Выбранный в приложении интервал сейчас сохраняется локально; он пока не управляет серверным сборщиком.

## Сборка APK

Откройте вкладку **Actions** в GitHub и запустите workflow **Build Android APK** через **Run workflow**. После успешной сборки APK будет доступен в артефактах запуска.
