# Мониторинг Костромской области

Самостоятельное Android-приложение. GitHub используется только для исходного кода и сборки APK. После установки приложение напрямую запрашивает публичные сайты и Telegram Web Preview; данные и настройки сохраняются локально.

## Реализовано в приложении
- 35 настроенных публичных источников: семь каналов, переданных пользователем, дополнительные Telegram-каналы, официальные ведомства и региональные СМИ. Это число настроенных адресов, а не гарантия доступности каждого из них.
- Прямое чтение публичных Telegram Web Preview, RSS/Atom и HTML-страниц.
- Поиск через Google Новости, Bing Новости и попытка обращения к Яндексу.
- Лента, фильтры по категории и периоду, выбор количества результатов, дедупликация и прямые ссылки на публикации.
- Статус каждого источника: публикации получены, ответ без подходящих публикаций, недоступен или отключён.
- Фоновое обновление через Expo BackgroundTask/Android WorkManager и переключатель фонового режима.
- Настраиваемые интервалы 5–1440 минут. В фоновом режиме Android ограничивает периодическую задачу минимумом 15 минут; запуск не гарантируется по минутам.
- Экран приватности и разрешений. Приложение не запрашивает контакты, SMS, звонки, микрофон, камеру, фото, файлы или геолокацию.
- Раздел карт с переходами к публичным интерактивным картам.

## Известные ограничения
- Фоновый интервал 5 или 10 минут не гарантируется: системный планировщик Android запускает периодические задачи не чаще чем примерно раз в 15 минут и может задерживать их из-за энергосбережения.
- Telegram Preview может менять разметку или ограничивать выдачу. Закрытые каналы автоматически не читаются.
- HTML-парсинг не гарантирует извлечение всех материалов; сайты могут менять структуру или блокировать автоматические запросы.
- Google, Bing и Яндекс могут ограничивать автоматизированный доступ. При недоступности Яндекса можно открыть его сайт через системный браузер; встроенного VPN нет. Приложение использует системный VPN Android, если он настроен пользователем.
- Карты открывают сторонние сервисы. Собственные координатные метки по каждой новости ещё не реализованы; приложение не придумывает координаты событий.
- В приложении нет системного firewall. Сетевые запросы раскрывают IP-адрес внешнему сервису; нельзя гарантировать абсолютную защиту от анализа или взлома.
- Нет аналитики, рекламных SDK или отправки личных данных телефона. Поисковые запросы отправляются выбранным поисковым системам.

## Сборка APK
GitHub → Actions → Build Android APK → Run workflow. После успешной сборки скачайте артефакт `kostroma-monitor-apk`. APK считается готовым только после успешной сборки и проверки артефакта.
