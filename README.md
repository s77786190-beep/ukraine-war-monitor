# Мониторинг Костромской области

Самостоятельное Android-приложение. GitHub нужен только для хранения кода и сборки APK. После установки новости загружаются с телефона напрямую из открытых источников.

## Реализовано в исходниках
- 24 настроенных источника: 7 указанных Telegram-каналов, дополнительные публичные Telegram-каналы, официальные сайты и СМИ.
- Прямой опрос Telegram Web Preview и попытка чтения RSS/Atom-лент с сайтов.
- Дополнительный поиск через Google Новости, Bing Новости и Яндекс.
- Локальная лента, категории, дедупликация, ссылки на оригиналы, переключатели источников.
- Фоновая задача Android WorkManager, переключатель включения/выключения и интервалы 5–1440 минут.
- Экран используемых разрешений и настроек приватности.
- Нет доступа к контактам, SMS, звонкам, микрофону, камере, фото, файлам или геолокации.

## Ограничения
Android WorkManager не гарантирует точное время запуска; минимальный период фоновой задачи — 15 минут. 5 и 10 минут не могут гарантироваться в фоне. Doze, энергосбережение и политика производителя могут задержать задачу.
Публичные Telegram preview-страницы могут быть недоступны или менять HTML. Закрытые каналы не читаются. Не все сайты имеют RSS, а текущий парсер не гарантирует извлечение каждой новости. HTML-страницы без RSS/Atom пока не разбираются как полноценные новостные ленты; для них нужны отдельные проверенные парсеры. Карта событий с геокодированием пока не реализована.
Встроенного VPN нет. Поисковые запросы отправляются выбранным поисковым системам. При включённом системном VPN Android приложение использует системный маршрут. Абсолютная защита от взлома, наблюдения и анализа трафика невозможна.
Лента и настройки хранятся локально; отдельного сервера приложения нет.

## APK
GitHub → Actions → Build Android APK → Run workflow. После успешной сборки откройте артефакт kostroma-monitor-apk.
