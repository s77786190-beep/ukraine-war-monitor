# Мониторинг Костромской области

Самостоятельное Android-приложение. GitHub используется для хранения исходного кода и сборки APK; после установки приложение напрямую обращается к публичным источникам и хранит результаты на устройстве.

## В исходниках
- 35 публичных источников: Telegram, официальные сайты и региональные СМИ.
- Прямой опрос публичных Telegram Web Preview, RSS/Atom и HTML-страниц сайтов.
- Поиск через Google Новости, Bing Новости и Яндекс (если доступен из текущей сети).
- Локальная лента, категории, дедупликация, ссылки на публикации, включение/отключение источников.
- Фоновая задача Android через Expo BackgroundTask/WorkManager; интервалы 5–1440 минут с реальным минимумом 15 минут для системной фоновой задачи.
- Экран разрешений и приватности; приложение не запрашивает контакты, SMS, звонки, микрофон, камеру, фото, файлы или геолокацию.

## Ограничения, которые нельзя скрывать
- WorkManager не гарантирует точный запуск. Минимальный период фоновой задачи — 15 минут; 5 и 10 минут в фоне не гарантируются. Doze и энергосбережение могут задерживать задачу.
- Telegram preview может быть ограничен или менять разметку; закрытые каналы не читаются.
- Сайты могут блокировать автоматические запросы, менять HTML, не иметь RSS. Универсальный парсер не гарантирует полноту публикаций. Недоступность источника показывается отдельно от нулевого числа новостей.
- Google, Bing и Яндекс могут блокировать автоматизированный доступ. Поисковые запросы передаются этим сервисам; VPN не встроен. При включённом системном VPN Android приложение использует системный маршрут.
- Карта с достоверными геокоординатами событий пока не реализована. Нельзя приписывать событию точное место, если оно не указано в публикации.
- «Фаервол» приложения не может защитить от любого взлома или сетевого наблюдения. В приложении нет аналитики и доступа к личным данным, но сетевой запрос раскрывает IP-адрес сервису, к которому обращается устройство.

## Сборка APK
GitHub → Actions → Build Android APK → Run workflow. После успешной сборки скачайте артефакт `kostroma-monitor-apk`.
