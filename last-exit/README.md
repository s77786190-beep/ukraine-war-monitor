# Последний выход — Android prototype

Играбельный вертикальный срез атмосферного 2D side-scroller. Первая глава — окраина разрушенного города; реализованы ходьба, прыжок, стрельба, ножевой выпад, враги, аптечка, боеприпасы, альтернативный проход и завершение главы.

## Сборка APK
В репозитории откройте **Actions → Build Last Exit Android APK → Run workflow**. После завершения успешного workflow скачайте артефакт **last-exit-debug-apk**. Это debug APK для установки и тестирования, не подписанный релизный пакет.

## Локальный запуск
Нужен Node.js 20+. Выполните `npm install`, `npm run build`, `npx cap add android`, `npx cap sync android`. Затем откройте каталог android в Android Studio или выполните `./gradlew assembleDebug`.

## Состояние разработки
Это ранний играбельный прототип, а не законченная игра. Пока реализована одна демонстрационная глава. Остальные девять уровней, полноценная физика ткани, продвинутая анимация ножевого боя, высокодетализированные арт-ассеты и оригинальный музыкальный саундтрек требуют следующих итераций. Графика прототипа процедурная и атмосферная, но пока не фотореалистичная.
